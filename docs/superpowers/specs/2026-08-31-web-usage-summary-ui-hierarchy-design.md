## 目标

让 Web 控制台的用量页与 Chrome 插件的真实信息架构一致，并沿用数据看板的视觉层级：

```text
API 令牌汇总 → 选中 API 令牌 → 渠道汇总 → 选中渠道 → 模型汇总
```

页面顶部的总览卡片和趋势信息可以跨令牌汇总，但任何明细列表都不得把渠道或模型混入 API 令牌一级维度。选中令牌后，新增独立标识的“跨渠道模型汇总”，仅汇总该令牌的模型，不取代“渠道内模型汇总”。

## 参考实现

本次交互依据 Chrome 插件仓库的实际实现，而不是照搬插件的请求机制：

- `src/sidepanel/sidepanel.html`：一级表格标题为“按 API 令牌”。
- `src/sidepanel/sidepanel.js` 的 `renderRows()`：点击令牌后更新当前令牌并重置渠道选择。
- `src/sidepanel/sidepanel.js` 的 `renderDetail()`：在当前令牌上下文中展示渠道；选择渠道后渲染“渠道内按模型”。
- `src/sidepanel/detail-state.js`：默认选择按总 Token 排序后的第一个渠道，并保持模型只属于渠道。

Web 页面只复用数据层的 Token → 渠道 → 模型归一化结果，不引入插件源码、Content Script、Cookie 或缓存。

## 页面结构

1. 顶部标题、时间范围、权限范围和刷新操作。
2. 四项总览卡片：总 Token（输入/输出为副行）、请求数、消耗额度、等价金额（人民币为主、美元为副）。
3. 每日总 Token 柱状趋势与“API 令牌分布”横条面板；分布只按 API 令牌的总 Token 计算占比。
4. “API 令牌汇总”表格：每行一个 API 令牌，展示请求数、总 Token（输入/输出副行）、消耗额度、双币种等价金额，点击进入该令牌明细。
5. 当前令牌明细卡：
   - 当前令牌摘要显示名称、总 Token、消耗额度和双币种金额；
   - 渠道汇总列表可点击；默认选中当前令牌总 Token 最高的渠道；
   - 渠道汇总与“按模型汇总（当前令牌 · 跨渠道合计）”并列，窄屏上下排列；
   - 同名模型跨渠道汇总时，累计请求数、输入/输出/总 Token、日志 quota，不修改原始渠道数据；
   - 下方“渠道内模型汇总”只渲染当前选中渠道的模型，两种模型视角不混淆。

## 交互和状态

- API 令牌表格使用公共 `StaticDataTable`；行保留 `aria-selected`，令牌/渠道按钮以 `aria-pressed` 表达选择态，支持键盘操作。
- 点击 API 令牌只改变本地选择，不重新请求接口；切换令牌时渠道选择重置为该令牌第一个渠道。
- 点击渠道只更新当前渠道和下方模型表，不改变 API 令牌和查询范围。
- Token、渠道、模型均按 `totalTokens` 降序，默认首项即最高消耗项。
- 空 Token、空渠道、空模型分别显示明确的空状态；加载、错误和已有缓存状态继续沿用一期页面行为。

## 数字显示

- 大数复用公共格式化函数并跟随界面语言；中文使用万/亿，英文使用 K/M 等；紧凑值最多一位小数。
- 详情表格和总览卡片保留完整数值到 `title` 属性，便于核对。
- “消耗额度”表示日志中的原始 `quota`，不等同于输入/输出 Token；大数紧凑显示并保留完整数值到 `title`。
- 等价金额按站点设置计算：`USD = quota / quotaPerUnit`，`CNY = USD × usdExchangeRate`。金额基于历史日志已扣额度，不使用当前模型价重新计费，不使用充值购买价，也不代表上游真实成本。
- 站点参数或语言改变时同步重算显示；无效兑换单位显示不可用，无效汇率只令人民币不可用，不冒充零元；小额保留最多六位小数，低于精度的非零值显示边界提示。
- 仅展示已消耗额度；不加入剩余额度、余额或订阅套餐额度。

## 兼容与边界

- 不修改 Go 后端聚合接口、数据库、Docker Compose、生产镜像或 `usage-logs` 页面。
- 不改变 `/api/log/usage-summary` 和 `/api/log/self/usage-summary` 的请求参数及权限选择。
- 实现集中在 `web/src/features/usage-summary/`，仅补充已有七种语言的翻译键及本设计说明；不修改公共 UI 组件、路由或依赖锁文件。
- 窄屏表格转为两列信息块，局部覆盖公共表格固定行高；趋势日期在图内滚动，避免裁切末尾标签。保留页面内侧安全间距，不裁切卡片边缘。
- 生产环境不参与本地开发预览和测试；正式镜像切换仍须另行审批。

## 验收标准

- 页面上可明确看到“API 令牌汇总”，不出现含义不清的“按 Token 汇总”。
- API 令牌表格不显示渠道或模型列作为一级维度。
- 选中 API 令牌后只显示它的渠道；选中渠道后只显示该渠道的模型。
- 切换令牌/渠道不会增加聚合接口请求次数。
- 大数字显示中文单位，悬停能取得完整值。
- 现有用量页的加载、空数据、错误、管理员/普通用户权限和 API 请求测试继续通过。
- 总览、令牌、渠道及两种模型明细均显示消耗额度和人民币/美元等价金额；跨渠道模型合计不混入其他令牌。
- 费用测试覆盖小额、零、负值、无效参数与配置变化；语言转换覆盖七种界面语言、非法语言降级及组件切换。
- 开发单测和合成数据浏览器验证不等于永久测试环境真实接口验收；后续构建镜像、部署和生产切换仍分别审批。
